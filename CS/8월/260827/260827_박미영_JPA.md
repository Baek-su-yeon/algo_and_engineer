### 2. JPA는 왜 등장했을까?
- Java에서는 데이터를 객체로 관리함.

```
Member member = new Member();
member.setName("미영");
member.setAge(25);
```

- 관계형 데이터베이스에서는 데이터를 테이블로 관리함.
| id | name | age |
| --- | --- | --- |
| 1 | 미영 | 25 |

- 객체에서는 다음과 같이 연관된 객체를 바로 참조 가능
```
member.getTeam();
```

- 데이터베이스에서는 member 테이블과 team 테이블을 외래 키로 연결해서 조회
```
SELECT *
FROM member m
JOIN team t ON m.team_id = t.id;
```

- 기존에는 Java에서 데이터베이스를 사용하기 위해 JDBC를 주로 사용
```
String sql =
    "INSERT INTO member(name, age) VALUES(?, ?)";

PreparedStatement pstmt =
    connection.prepareStatement(sql);

pstmt.setString(1, member.getName());
pstmt.setInt(2, member.getAge());

pstmt.executeUpdate();
```

- 조회할 때는 데이터베이스의 조회 결과를 다시 Java 객체로 변환
```
ResultSet rs = pstmt.executeQuery();

Member member = new Member();
member.setId(rs.getLong("id"));
member.setName(rs.getString("name"));
member.setAge(rs.getInt("age"));
```

### 6. JPA가 객체와 테이블을 어떻게 연결하는가?
```
@Entity // JPA가 관리할 클래스라는 뜻
@Table(name = "member") // 연결할 테이블 지정
public class Member {

    @Id // 기본 키
    @GeneratedValue // 기본 키 자동 생성
    private Long id;

    @Column(nullable = false) //연결할 열과 제약조건 설정 
    private String name;

    private int age;
}
```

### 7. 매핑한 Member 객체, 어떻게 데이터베이스에 저장하나?
```
// 저장 -> INSERT
entityManager.persist(member);

// 조회 -> SELECT
Member member =
    entityManager.find(Member.class, 1L);

// 삭제 -> DELETE
entityManager.remove(member);
```
